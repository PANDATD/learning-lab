# SQLite CLI

## Purpose

Learn how to navigate the SQLite shell before writing SQL.

## Common SQLite Commands

| Command | Purpose |
|----------|---------|
| `.help` | Display available SQLite CLI commands |
| `.databases` | Show connected databases and their file paths |
| `.tables` | List all tables in the current database |
| `.schema` | Show the database schema (table definitions) |
| `.quit` | Exit the SQLite shell |

## Key Learning

- SQLite CLI commands start with `.`
- CLI commands are different from SQL commands.
- `.tables` lists existing tables.
- `.schema` shows the database structure, not the data.
